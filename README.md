# Stacks — releases

Signed, notarised macOS builds of **Stacks**, a sample manager for external drives and SD cards: key and BPM on
import, a sample editor with auto loop, and drag straight into your DAW.

**[Download the latest version](https://github.com/justynroberts/stacks-releases/releases/latest)** — open the
`.dmg` and drag Stacks to Applications. macOS 13 (Ventura) or later, Apple silicon or Intel.

Installed copies update themselves from this page: a new version downloads in the background and Stacks asks
before it restarts. This repository only holds the installers and the update manifest.
